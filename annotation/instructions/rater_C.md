# Instructions for Rater C (40 sentences)

Thank you for helping. You will rate how natural some romanized Kannada sounds.

**What you need:** the file `rater_C.xlsx` from Aarnav, and Excel (on a laptop or desktop if you can; the Excel
phone app also works).

## Getting started
1. Open `rater_C.xlsx` and type your name in the yellow cell on the sheet **READ_ME**.
2. Go to the sheet **items**. Only the yellow cells can be changed.

## For each row
You see a Kannada sentence and two versions of it typed in Latin letters. The column "Kind" says whether they are
**natural romanization** (the Kannada typed in Latin letters, word for word) or **Kanglish** (the same message as a
young person in Bengaluru would write it on WhatsApp, with English words mixed in).

Rate **each** version for naturalness with the dropdown:
- 1: nobody would type this
- 5: exactly how people type on a phone

Rate each version on its own merits. Both can get the same rating, high or low. Do not try to guess who or what wrote
a version. There are 80 rows in total (40 sentences, each in both kinds).

## Rules
- Go with your first impression; there are no right answers.
- Do not use translation tools, AI tools or dictionaries.
- Do not discuss the items with anyone, including others working on this project.

## Sending your work
- Save as an Excel Workbook (.xlsx), never as CSV, and send the .xlsx to Aarnav on WhatsApp when you finish.
- If something does not work, ask Aarnav.
