# Instructions for Rater C (40 sentences)

Thank you for helping. You will rate how natural some romanized Kannada sounds.

**What you need:** the file `rate_k3_v1.html` from Aarnav, and any up-to-date browser on a laptop or desktop.

## Getting started
1. Open `rate_k3_v1.html`.
2. Type your name in the "Rater" box. Use exactly the same name every time.

## For each item
You see a Kannada sentence and two versions of it typed in Latin letters. Some items are **natural romanization**
(the Kannada typed in Latin letters, word for word); others are **Kanglish** (the same message as a young person in
Bengaluru would write it on WhatsApp, with English words mixed in).

Rate **each** version for naturalness:
- 1: nobody would type this
- 5: exactly how people type on a phone

Rate each version on its own merits. Both can get the same rating, high or low. Do not try to guess who or what wrote
a version. Then click "Save and next". There are 80 items in total (40 sentences, each in both kinds).

## Rules
- Go with your first impression; there are no right answers.
- Do not use translation tools, AI tools or dictionaries.
- Do not discuss the items with anyone, including others working on this project.
- You can stop and come back: your ratings stay in this browser on this computer. Use the same browser and computer.

## Sending your work
- When you finish (or at the end of each session), click "Download CSV" and send the file to Aarnav.
- If something does not work, ask Aarnav.
