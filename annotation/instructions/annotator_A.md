# Instructions for Annotator A (500 items)

Thank you for helping. You will check and correct romanized Kannada written by an AI model.

**What you need:** the file `annotator_A.xlsx` from Aarnav, and Excel (on a laptop or desktop if you can; the Excel
phone app also works).

## First: check the worked examples (send within a day)
1. Open `annotator_A.xlsx` and go to the sheet **worked_examples**. It shows 3 sentences that are not among your
   items: the AI draft, how it was rated, and a good correction.
2. For each row choose **OK** or **needs correction** in the yellow column. If something is wrong (a rating, a
   correction, a spelling, a meaning), write your correction or comment in the last column.
3. Save the file and send it to Aarnav within a day. Then start the items.

## Before you type anything
- Turn off AutoCorrect in Excel: File > Options > Proofing > AutoCorrect Options, and untick "Correct TWo INitial
  CApitals", "Capitalize first letter of sentences" and "Replace text as you type".
- On a phone or tablet, also turn off autocorrect and automatic capitals in your keyboard settings.
- Type your name in the yellow cell on the sheet **READ_ME**. Use exactly the same name every time.

## For each item (sheet "items", one row per item)
You see a Kannada sentence, its English translation, and two AI drafts:
- **Natural romanization:** the Kannada typed in Latin letters, the way people type on a phone, word for word.
  English words that are already in the Kannada stay as they are.
- **Kanglish:** how a young person in Bengaluru would write the same message on WhatsApp, with English words mixed in
  where that is natural. It must keep the full meaning.

For each draft:
1. **Rate it first, before changing anything.** Use the dropdowns in the yellow cells.
   - Naturalness: 1 (nobody would type this) to 5 (exactly how people type).
   - Meaning: does it keep the meaning of the Kannada sentence? yes or no.
2. **Then correct it** in the column "your corrected version", which starts as a copy of the draft. Change it so it
   reads naturally and keeps the full meaning. If it is already fine, leave it unchanged.

Only the yellow cells can be changed; the rest of the sheet is locked so nothing is deleted by accident.

## Rules
- Write the way you would really type. There is no single correct spelling.
- Do not use translation tools, AI tools or dictionaries.
- Do not discuss items with anyone else working on this project.
- Use the Note column for anything odd (for example, a Kannada sentence that is itself wrong).

## Pace and sending your work
- About 25 items a day works well (about 2 minutes per item). Short sessions are fine: save (Ctrl+S) and close.
- Always save as an Excel Workbook (.xlsx), never as CSV.
- At the end of each week, send the .xlsx file to Aarnav on WhatsApp (attach it as a Document).
- If something does not work, or a question comes up, ask Aarnav.
