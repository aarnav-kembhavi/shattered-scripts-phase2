# Instructions for Annotator B (100 items)

Thank you for helping. You will write romanized Kannada yourself, and check versions written by an AI model.

**What you need:** the file `annotate_v2.html` from Aarnav, and Chrome or Edge on a laptop or desktop.

## Getting started
1. Open `annotate_v2.html` in Chrome or Edge.
2. Type your name in the "Annotator" box. Use exactly the same name every time.
3. Select **"Second annotator (100 items)"**. Never use "All 500 items": it shows AI versions of the first 40 items.
4. Click "New CSV file…" and save the file somewhere you will find again. Next time, click "Continue a CSV file…" and
   pick the same file.

## Part 1: the first 40 items (do these first, before anything else)
You see only a Kannada sentence. Write two versions of it yourself, from scratch:
- **Natural romanization:** the Kannada typed in Latin letters, the way you would type it on a phone, word for word.
  Keep English words that are already in the Kannada as they are.
- **Kanglish:** how a young person in Bengaluru would write the same message on WhatsApp, with English words mixed in
  where that is natural. Keep the full meaning.

Click "Save and next". There is nothing to rate in Part 1. Finish all 40 before you go further, and do not click ahead
to look at later items.

## Part 2: the other 60 items
Now you see the Kannada sentence, its English translation and two AI drafts. For each draft:
1. **Rate it first, before changing anything:** naturalness from 1 (nobody would type this) to 5 (exactly how people
   type), and whether it keeps the meaning (yes or no).
2. **Then correct it** in the box. If it is already fine, leave it unchanged.
3. Click "Save and next".

## Rules
- Write the way you would really type. There is no single correct spelling.
- Do not use translation tools, AI tools or dictionaries.
- Do not discuss items with anyone else working on this project, and do not look at anyone else's work.
- Use the Note box for anything odd.

## Sending your work
- **When Part 1 (the 40 items) is done, send your CSV file to Aarnav straight away**, then continue with Part 2.
- Send the CSV again when you finish. If something does not work, ask Aarnav.
